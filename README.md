Hi. upload this code to arduino IDE connected to your ESP32 and make sure to download the libraries included at the top of the code. Change the pins according to the code or change the code according to the pins you are using. 


INSTRUCTIONS:

1. put everything on the breadboard and wire it.
2. Print both STL files (1 and 2)
3. get a cardboard box or some sort of thing as the safe
4. Glue on the 3d print to the box. Add the electronics
5. Upload code from Arduino IDE to ESP32
6. run

PARTS YOU NEEED:

ESP32. 2 breadboards. 1 RFID RC522. 1 .96 inch OLED. 1 passive buzzer. 1 SG90 servo. 3d printer. a bunch of wires(comes with most kits.)

I bought the ELEGOO super starter kit it had everything I needed to complete this project
